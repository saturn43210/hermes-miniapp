📖 راهنمای کامل Hermes Agent

تمام دستورات و توضیحات کامل

هرمس یک دستیار هوش مصنوعی پیشرفته هست که می‌تونه کارهای زیادی انجام بده. در زیر لیست کامل دستورات رو می‌بینید:
💬 دستورات چت
/help — نمایش راهنمای کامل
/status — وضعیت سیستم و منابع
/new — شروع چت جدید
/memory — مشاهده حافظه هوش مصنوعی
🤖 مدیریت مدل
/model [name] — تغییر مدل هوش مصنوعی
/model list — لیست مدل‌های موجود
⏰ کرون‌جاب‌ها
/cron list — لیست جاب‌های فعال
/cron run [id] — اجرای دستی یک جاب
/cron run all — اجرای تمام جاب‌ها
/cron pause [id] — توقف موقت یک جاب
🎯 مهارت‌ها
/skill list — لیست مهارت‌های نصب شده
/skill [name] — نمایش جزئیات یک مهارت
/skill delete [name] — حذف یک مهارت
💾 بکاپ و بازیابی
/backup now — بکاپ فوری
/backup restore — بازیابی از بکاپ
🔍 باگ‌بونتی و امنیت
/aisos — نمایش وضعیت AISOS Database
/aisos run — اجرای AISOS Engine
🌐 زبان و تنظیمات
/language [fa|en]
تغییر زبان مکالمه. فارسی پیش‌فرض هست.
/clear
پاک کردن تاریخچه چت فعلی.
/session
نمایش اطلاعات جلسه فعلی.
🛠️ ابزارها
/terminal [command]
اجرای دستور ترمینال.
/file [read|write] [path]
خواندن یا نوشتن فایل.
/search [query]
جستجو در اینترنت.
📊 اطلاعات
/whoami
نمایش اطلاعات کاربر.
/history
تاریخچه دستورات اجرا شده.
/stats
آمار کلی استفاده.
